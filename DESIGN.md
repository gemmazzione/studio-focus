# Studio visual system
Operate mode. Quiet reading-room aesthetic: ivory paper, ink typography, moss green actions, terracotta emphasis. Spacious working canvas beside a narrow navigation rail. Main task dominates; secondary information uses ruled lists. Serif headings, sans-serif interface, tabular timer. No decorative illustrations. Responsive single column on small screens. Focus mode removes secondary navigation visually. Visible keyboard focus and reduced-motion support.
Tokens: background #f6f5ef, surface #fffef9, ink #243b32, secondary #59665e, accent #315c48, line #d8ddd2, warm #9a4a30. Radius 12px; spacing 8/16/24/32/48px.
